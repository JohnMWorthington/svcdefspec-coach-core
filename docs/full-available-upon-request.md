# FULL Edition — Available Upon Request


SvcDefSpec Coach FULL is available to approved professionals and organizations under a separate no-cost license and recipient-approval process.


FULL is intended for users who need capabilities beyond normal CORE use, such as:
- governed professional deployment;
- enhanced artifact execution;
- advanced controlled rule/reference material;
- approved peer-review/assurance material;
- MCP/API integration;
- organization-specific adapters;
- controlled deployment and extension guidance.


## FULL is not public-source material


FULL is not stored in this public repository and is not distributed through a hidden branch.


Approved recipients receive a versioned controlled package or access to a private release/repository.


## Integration


External MCP/API/app integration is off by default.


A FULL + Integration deployment must identify:
- the extension/integration;
- owner;
- purpose;
- connected systems;
- authentication/authorization model;
- read/write capabilities;
- data handling;
- human approval requirements;
- supported Coach version;
- testing status.


## Request process


Typical sequence:


1. Request FULL.
2. Describe intended professional/organizational use.
3. Review applicable rights and restrictions.
4. Execute the SvcDefSpec Coach FULL/Extension & Deployment agreement.
5. Receive recipient approval and the correct versioned package.
6. Configure and test the approved environment.
7. Register integrations where applicable.


The owner may decline or limit distribution where the requested use would conflict with the licensing, IP, security, or method-governance model.
