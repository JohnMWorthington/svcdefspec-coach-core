# Service Definition & Specification Coach — CORE


**Version:** 0.1.28  
**Status:** Controlled Release — open for practical field use and feedback


The Service Definition & Specification Coach (SvcDefSpec Coach) helps people define, reconstruct, clarify, specify, and improve a service relationship using an outside-in, evidence-aware method.


It is designed to work in ChatGPT, Claude, and other capable AI environments without requiring MCP, APIs, or proprietary automation.


## What CORE does


CORE helps you:
- understand what the service actually is;
- distinguish Customer, Provider, Users, Facility, Support, Functionality, and Functioning;
- reconstruct a current service from existing agreements and evidence;
- identify Moments of Truth and Useful Completion;
- preserve Current / Future / Open distinctions;
- identify a small representative set of customer-to-provider interactions;
- distinguish dependencies from supporting services;
- perform a USM Alignment & Gap Review before redesign;
- separate current clarification, better agreement expression, and genuine future design;
- hand off cleanly to downstream USM workflow/process design.


## Three phases


1. **See it + Specify it** — reconstruct and model the current service.
2. **Operate it** — identify representative customer-to-provider interactions and high-level provider responsibilities.
3. **Agree it** — align the service definition to the USM Service Agreement structure and identify material gaps before drafting or redesign.


The Coach deliberately stops before detailed USM workflow/process/request design.
