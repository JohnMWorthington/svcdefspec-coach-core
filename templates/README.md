# Templates

This directory is intended to contain the two public CORE templates:

- `Service-Model-Map-Template.pptx`
- `USM-Service-Model-Canvas.xlsx`

These are controlled binary files. They should be uploaded unchanged from the approved v0.1.26 release source.

Until both files are present, the Coach remains usable: `core/svcdefspec-core.md` requires the host to provide equivalent logical Map and Canvas views as structured text/tables when editable artifact generation is unavailable.

Do not substitute modified or independently recreated templates without release review.
